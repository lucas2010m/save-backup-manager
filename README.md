## 🛠️ Troubleshooting and Common Issues

Even with the best tools, questions can arise. Here's a quick guide to common situations:

### ❌ Q: My game isn't detected in the standard folder list.

**A:** Games store saves in different places. The most common locations are:
- `C:\Users\[Your Username]\Documents\My Games`
- `C:\Users\[Your Username]\AppData\Local`
- `C:\Users\[Your Username]\AppData\Roaming`
- Inside the game's installation folder on the Steam/Epic drives.

If you're unsure, launch the game, play for a minute, save it, and then search your computer for files that changed at that exact time. You can also check online guides for your specific game's save folder location.

### ⚠️ Q: The application says "Backup Failed."

**A:** This almost always means the destination folder path is incorrect or not writable. Make sure you have permission to write to the destination folder you chose, and that the drive is properly connected.

### 🔐 Q: My game saves are in a protected Windows folder.

**A:** This is normal. When you select the folder, just be sure you clicked "Allow" if Windows asks for permission. save-backup-manager follows your instructions and should be able to read those folders if you ran the application normally.

### 💡 Q: When should I restore a backup?

**A:** Use restore when you've lost progress, a game has corrupted its files, or you simply want to revisit an older save file. Always be careful when restoring, as the restore overwrites your current save data.

### ⏰ Q: The scheduled backup isn't running.

**A:** Check if the application is closed. For scheduled backups to run, save-backup-manager needs to be open, or running in the system tray. Look for its icon near the clock in the bottom-right corner of your screen.
