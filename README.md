## About

Every save-editing mishap ends with 'I wish I had a backup' — prevention first.

## Feature map

| Area | Design goal |
|---|---|
| **Principle** | Watch folders per store (Steam, Epic, Xbox) |
| **Detail** | Pre-edit automatic snapshots |
| **Focus** | Cloud-sync optional (your own drive) |
| **Goal** | Restore wizard |
| **Scope** | Disk-space rotation rules |

## Usage walkthrough

**Step 1.** Click the large Download button above (it points to the project's release page).
**Step 2.** Unpack the archive to a folder you control — no installer needed.
**Step 3.** Open the included README section for the feature you want before running anything.
**Step 4.** Make a backup / snapshot when the workflow calls for one. Always.
**Step 5.** Run the tool, apply what you need, and close it. Nothing stays resident.
